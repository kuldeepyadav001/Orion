name: orion-docs

# The second evaluation suite: Orion's own documentation, chunked by the
# real chunker into a few hundred chunks of real prose.
#
# The M2 suite is 22 chunks. That is easy — a retriever that returns the
# four nearest neighbours out of twenty-two is not being tested. This suite
# exists to answer one question: does the ranking decision (dense-first,
# one reserved lexical slot) survive when the corpus is two hundred chunks
# of real prose instead of twenty-two synthetic ones?
#
# Ground truth is a TEXT ANCHOR, not a chunk id, so the suite survives the
# documents being edited. Every anchor of a question must appear in the
# same chunk. If several chunks match, all are accepted: a retriever that
# finds any copy of the answer has found the answer.
#
# `source <substring>` restricts the search to one document. It is used by
# the disambiguation questions, where two documents legitimately say
# different things and the question asks about one of them specifically.
#
# Format:
#   question <id> | <text>
#   anchor <phrase>
#   probe <paraphrase|exact|heading|disambiguation>
#   source <path substring>
#   unanswerable
